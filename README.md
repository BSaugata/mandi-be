## Setup local env

### Pre-requisite
- Install docker like Rancher or OrbStack
- Install VS Code
- Install vs code extension:
  - Dev Containers
  - Excalidraw
  - Rainbow Csv

### Steps
- Clone the repo and open on vs code dev containers
- Setup Git 
  
  ```bash
  git config --global user.name "Your Name"
  git config --global user.email "your.email@example.com"
